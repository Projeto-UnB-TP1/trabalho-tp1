# Trabalho TP1
Trabalho do projeto de TP1 para um modelo de app de gerencia de projetos em KANBAN.

## Como compilar

Abra `trabalho-tp1.cbp` no Code::Blocks e escolha o alvo na barra de compilação:

- **Sistema**: o aplicativo Kanban (`main.cpp`), gerado em `bin/Sistema/kanban`.
- **Testes**: os testes de unidade dos domínios e entidades (`Testes/main_testes.cpp`), gerado em `bin/Testes/testes`.

Os dois alvos ficam separados porque cada um tem a sua própria função `main`.
